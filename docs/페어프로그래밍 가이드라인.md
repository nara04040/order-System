
# AI-인간 페어프로그래밍 가이드라인

성공적인 페어프로그래밍을 위해 다음과 같은 방식으로 진행하는 것이 효과적일 것 같습니다:

### 1. 역할 분담
- **드라이버/네비게이터 역할 교대**: 특정 기능 구현 시 한쪽이 코드를 작성(드라이버)하고 다른 쪽이 방향을 제시(네비게이터)
- **AI 역할**: 코드 제안, 설명, 리팩토링 제안, 문제 해결 가이드
- **인간 역할**: 최종 결정, 요구사항 명확화, 피드백 제공

### 2. 단계별 진행 방식
1. **계획 단계**: 구현할 기능 정의
2. **설계 단계**: AI가 코드 구조 제안
3. **구현 단계**: 모듈별로 코드 작성
4. **검토 단계**: 작성된 코드 검토 및 개선
5. **통합 단계**: 모듈 통합 및 테스트

### 3. 의사소통 규칙
- **명확한 지시**: "이제 X 모듈을 구현하자" 같은 명확한 지시
- **코드 리뷰 요청**: "(코드리뷰) 이 코드의 문제점이 있는지 검토해줘"
- **질문과 피드백**: (질문) 서로의 이해를 높이기 위한 질문

### 4. 코드 공유 방식
- AI는 완성된 코드 블록 제공
- 인간은 코드에 대한 피드백이나 수정 요청
- 문제 발생 시 오류 메시지 공유

### 5. 진행 상황 확인
- 각 단계 완료 후 간략한 요약
- 다음 단계로 넘어가기 전 확인
- 정기적인 진행 상황 체크

이런 방식으로 진행하면 체계적이고 효율적인 페어프로그래밍이 가능할 것 같습니다. 어떻게 생각하시나요?
